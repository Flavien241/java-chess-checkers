# Chess and Checkers in Java

Object-oriented Java project implementing the foundations of chess and checkers (draughts), with board models, piece movement rules and console/desktop views.

## Features

- Chess board and individual chess pieces (king, queen, rook, bishop, knight and pawn)
- Checkers board with regular and king pieces
- Move and accessible-square logic
- Console and graphical window views
- Separate classes for game state, boards, pieces and user interface

## Project structure

- `ChessPieces/`: chess-piece classes
- `PlateauEchecs.java` and `PlateauDames.java`: board implementations
- `Jeu.java` and `JeuDamier.java`: game logic
- `MaVueConsole.java` and `MaFenetre.java`: console and desktop presentation
- `Main.java`: entry point

## Run locally

Compile the Java sources and run `Main.java` from a Java IDE or terminal.

## Scope

Academic project illustrating object-oriented modelling, inheritance and graphical/console interfaces in Java.
